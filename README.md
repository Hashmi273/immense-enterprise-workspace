# Immense Enterprise Workspace

Central Portal for Unified Enterprise Access Control & Application Launching.

## Overview
Immense Enterprise Workspace (`portal.immense.in`) serves as the single secure entrypoint for all internal operations:
- **Error Code Intelligence Hub** (Immense Air - Support/Operations)
- **Immense Air Quotation Manager** (Immense Air - Sales)
- **Zion Quotation Manager** (Zion - Sales)

## Stack
- React 18 + TypeScript + Vite
- Tailwind CSS
- Lucide Icons
- Supabase JS (Auth & Row Level Security)
